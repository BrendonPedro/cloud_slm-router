Not Diamond is an intelligent AI model router and prompt optimization that helps developers improve AI accuracy while radically reducing inference spend. Key Features Intelligent model routing : Use our pre-trained router to get started in less than 5 minutes, or train custom routers using your data. Automatic prompt optimization : Automatically optimize prompts to improve accuracy and to seamlessly adapt to new models as needed. Python , TypeScript , and REST API support : Seamlessly integrate Not Diamond across a variety of technology stacks. Getting Started You can make your first API request with Not Diamond in less than 5 minutes. Here's how to get started: Create an account at app.notdiamond.ai Generate a Not Diamond API key Jump into the routing quickstart or the prompt optimization quickstart .
