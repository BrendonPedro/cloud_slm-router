# What is Not Diamond?

Not Diamond is an intelligent AI model router and prompt optimization that helps developers improve AI accuracy while radically reducing inference spend.

## Key Features

* **[Intelligent model routing](https://docs.notdiamond.ai/docs/what-is-model-routing)**: Use our pre-trained router to get started in less than 5 minutes, or train custom routers using your data.
* **[Automatic prompt optimization](https://docs.notdiamond.ai/docs/what-is-prompt-optimization)**: Automatically optimize prompts to improve accuracy and to seamlessly adapt to new models as needed.
* **[Python](https://pypi.org/project/notdiamond/), [TypeScript](https://www.npmjs.com/package/notdiamond), and [REST API](https://docs.notdiamond.ai/reference) support**: Seamlessly integrate Not Diamond across a variety of technology stacks.

## Getting Started

You can make your first API request with Not Diamond in less than 5 minutes. Here's how to get started:

1. Create an account at [app.notdiamond.ai](https://app.notdiamond.ai)
2. Generate a [Not Diamond API key](https://app.notdiamond.ai/keys)
3. Jump into the [routing quickstart](https://docs.notdiamond.ai/docs/quickstart-routing) or the [prompt optimization quickstart](https://docs.notdiamond.ai/docs/quickstart-prompt-optimization).
